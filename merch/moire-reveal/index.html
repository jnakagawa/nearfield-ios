Technique: band-moiré magnification / sampling-moiré (Hutley; Kamal, Voelkel & Alda 1998; Amidror; Hersch & Chosson band-moiré, SIGGRAPH 2004 — the effect on banknote threads). 1-D line (default, best for text): base = thin bands at pitch pb, each a vertically-squashed whole wordmark; cling = a line grating at pr near pb; sampling magnifies vertically by M = pr/(pr-pb) while horizontal stays 1:1, so letters keep full crispness. A cling shift moves the reveal by M times the shift (optical speedup) — translation just repositions the (periodic) word, so it's essentially free. Wrong pr just rescales M — forgiving to about 10-15%. The catch: a rotation tilts the reveal by M times the angle, which for a 1-D magnifier shears the vertical mapping, so it holds only to about 0.5-1°. 2-D dot mode (pinhole array over a grid of tiny whole wordmarks) magnifies both axes and tolerates more rotation, but reconstructs text only at ~M samples across, so a fine wordmark reads coarsely — better for bold marks. Drag the canvas to move the cling; arrow keys nudge (Shift = 5px).
