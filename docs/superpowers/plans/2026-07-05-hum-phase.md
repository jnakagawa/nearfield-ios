# Hum Phase Implementation Plan (hub + iOS VoiceEngine)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spec §10 phase 3 — hub server + iOS `HubClient` + `VoiceEngine`: phones join the
hub, receive an assignment, and play their pitch in the derived tuning. Verified
end-to-end with the app in the iOS Simulator against a live hub on this Mac.

**Architecture:** Single-file asyncio `hub/hub.py` (websockets 15) owns assignment
(mirrors the tested JS `assignRoles`), serves configs in the `assign` payload, broadcasts
`score_position` at 1 Hz when the score runs. New XcodeGen target `NearfieldEnsemble`
(SwiftUI, iOS 16): `HubClient` (URLSession WebSocket, auto-reconnect),
`VoiceEngine` (AVAudioSourceNode 4-partial sine stack → EQ (shelf+lowpass) →
AVAudioUnitReverb approximating §5.5 — generated-IR convolution deferred to Piece),
minimal status UI. v1 target untouched.

**Tech Stack:** Python 3 + websockets (installed), pytest; Swift/SwiftUI, AVFoundation;
XcodeGen 2.44; `xcodebuild` + `simctl` for headless verification.
